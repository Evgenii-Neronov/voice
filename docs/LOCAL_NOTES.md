# Локальные условия и ограничения

Проверено 2026-11-04. Исходный репозиторий был чистым: main, origin/main, commit `4e7f6e9dea879f0a067daef005eb1b75b2d47496`. Remote: https://github.com/Evgenii-Neronov/voice.git. Запись, commit и push доступны; первый checkpoint `f3b745c` отправлен успешно.

ПК: Windows 11 Pro, i7-11700K (8 ядер / 16 потоков), около 64 GiB RAM, RTX 5080 16303 MiB, драйвер 610.88. До установки на I: было 216863453184 байт свободно (~202 GiB). До генерации другие приложения занимали примерно 9.1 GiB VRAM. Приложения пользователя не закрывались. Фактические снимки находятся в environment.json и gpu-before.csv.

CUDA smoke test прошёл: torch 2.10.0+cu128, compute capability (12, 0), успешная операция с CUDA tensor. Общесистемные Python/пакеты не заменялись.

Pinokio установлен как клиент pterm, но управляющий сервис отказал в соединении по localhost и настроенному LAN-адресу. Это не доказывает повреждения установки; переустановка не проводилась, поскольку прямой запуск работает и отвечает задаче воспроизводимости.

В I:/Repos обнаружены XTTS-v2 и GLM-4-Voice с весами, а также StyleTTS2Example. XTTS использует WSL Python 3.12 и рабочий torch 2.10+cu128. Новые веса с этими моделями не дублируются; старые каталоги и существующие голосовые записи оставлены без изменений.

## Отличия от полного upstream-окружения

- Qwen: flash-attn не установлен, используется SDPA. Импорт выводит предупреждение об отсутствии внешнего SoX, но все 9 WAV созданы через используемый путь без SoX. Нельзя считать предупреждение причиной несуществующего сбоя.
- Chatterbox: torch/torchaudio 2.10 заменяют upstream pin 2.6 для поддержки Blackwell. Gradio не установлен, поскольку UI не используется. Эти три расхождения видны в chatterbox-pip-check.txt. Импорт и фактический синтез — отдельная проверка работоспособности.
- Chatterbox: дополнительный russian_text_stresser отсутствует. Модель получает русский текст без автоматической расстановки ударений.
- Chatterbox автоматически загрузил вспомогательный китайский сегментатор spacy_ontonotes даже для русского теста. Созданные в этом запуске файлы перенесены из .pkuseg в `.cache/pkuseg`; runner теперь задаёт PKUSEG_HOME. ZIP SHA256: `b216e7f92de7ae285aeab8feba2faa8ea8216e5995ff6fb3d391cc8356db1bfe`. Он не является голосовой моделью.
- Китайская таблица Cangjie автоматически кэшируется внутри models/chatterbox. Этот upstream-вызов использует main; для русского текста таблица не применяется. Поэтому зафиксированные основные веса и параметры не являются обещанием полной герметичности всех языковых frontend-компонентов.
- ACE использует только inference-зависимости. Предупреждения об отсутствии Lightning, LyCORIS и bitsandbytes относятся к необязательным тренировочным функциям. Их наличие само по себе не означает провал генерации.
- Первая инициализация ACE остановлена: upstream требовал наличие весов LM даже при thinking=False и запустил ненужную загрузку. В run-ace.py введена явная проверка трёх необходимых компонентов, загрузка работает offline. Частично скачанные дополнительные файлы остались только внутри игнорируемого models/ace. Первая попытка отражена как interrupted_setup, повторная — отдельным manifest.
- ACE синхронизирует два Python-файла checkpoint с закреплённым git-кодом. Поэтому для повторения важны оба SHA: весов и source. Turbo принудительно использует guidance_scale=1.0, что видно в журнале; запрошенный dataclass default 7.0 в первом успешном запуске не является эффективным CFG.

## Что ещё не проверено

Fish S2/Drama 3, Higgs TTS 3, CosyVoice 3, OmniVoice: изучены официальные материалы, сняты SHA и размеры в research-models.json; локальный синтез этих моделей не выполнялся. Размер всего HF-репозитория не равен VRAM и может включать несколько компонентов.

Seed-VC: изучен режим singing voice conversion, но преобразование вокала не запускалось. Нужен заранее выбранный сухой вокальный источник и голосовой референс. Для точного сохранения мелодии у upstream применяется `inference.py --source source.wav --target reference.wav --output output --diffusion-steps 40 --length-adjust 1.0 --inference-cfg-rate 0.7 --f0-condition True --auto-f0-adjust False --semi-tone-shift 0 --fp16 True`. Это справочная команда, не отчёт об исполнении и не установленный здесь стек Seed-VC.

Нет слуховых оценок эксперта, ASR/WER, проверки нот MIDI, многосидовой статистики, чистой машины без фоновой GPU-нагрузки или замера latency первого аудиопакета. Выводы о качестве и пригодности к стриму ограничены этими обстоятельствами.
