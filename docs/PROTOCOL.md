# Воспроизводимый протокол

Все тексты в benchmark/cases.json сочинены для этого теста. Чужие песни, записи и голоса из I:/Repos не публикуются.

1. Закрепить SHA весов через download.py; повторные загрузки читают models.lock.json. Зафиксировать pip freeze и SHA исходников.
2. Один процесс и одна модель на GPU. Не завершать приложения пользователя ради памяти. Записать доступную память перед запуском.
3. Seed 20261104, одинаковые тексты; первичный smoke test, затем все 9 случаев. Для оценки устойчивости повторить с seeds 20261105 и 20261106. Один seed не доказывает стабильность.
4. WAV PCM16 без постобработки; сохранить текст, эффективные параметры, время, длительность, RTF, sample rate, peak, RMS, clipping fraction и SHA256. Пик torch allocated не равен всей занятой видеопамяти.
5. Ошибки сохранять в manifest.json; не заменять провал заранее записанным аудио. generated_unrated означает только полученный файл, а не хорошую речь.

## Слуховая оценка 1–5

Слушать вслепую, выравнивая громкость только в плеере: разборчивость русского, ударения/акцент, естественность, узнаваемость заданной эмоции, сила эмоции, сохранение тембра, артефакты. Отдельно отметить пропуски и добавленные слова. При двух оценщиках хранить независимые оценки.

Пара neutral_control/emotion_control содержит одинаковый текст: сравнивать действие доступного управления. У Chatterbox exaggeration меняет интенсивность, но не обещает joy; у Qwen 0.6B инструкция отключена и это явно записано.

## Протяжность и пение

drawl: обычная орфография + инструкция; syllables: повтор гласных в тексте. Измерить удержание гласных, а не суммарную длительность файла. Цель — около 2 секунд непрерывной фонации, без перечисления букв.

singing_probe у TTS — диагностический запрос вне гарантированных возможностей, не доказательство полноценного SVS. Проверять наличие устойчивой мелодии, вибрато, протяжных гласных и сохранение текста.

Для ACE-Step: оригинальные 4 строки, 30 секунд, 80 BPM, A minor, русский, одна и та же конфигурация для 3 seeds. Оценивать разборчивость, мелодичность и повторяемость отдельно от речи.

Для Seed-VC: записать или синтезировать оригинальную сухую вокальную фразу, зафиксировать SHA256 источника и референса. Сравнить F0/ритм до и после. Пока подходящего источника нет — статус blocked_missing_source, а не failed_model. Точное следование нотам проверять отдельным MIDI/score-тестом, не объявлять по свободной песне.
