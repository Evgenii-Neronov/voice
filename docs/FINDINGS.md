# Выводы первого локального benchmark

Все оценки качества пока `generated_unrated`: WAV действительно синтезированы здесь, но автоматическая проверка файла не заменяет прослушивание. Полная таблица — [results/SUMMARY.md](../results/SUMMARY.md), исходные параметры — в manifest.json каждого запуска.

## Речь

Qwen3-TTS 1.7B CustomVoice: 9/9 WAV, 24 kHz mono PCM16. После первого теста RTF примерно 7.3–7.7. Максимум torch allocated около 4.17 GiB. Это базовая Windows/SDPA-конфигурация на занятой другими приложениями видеокарте, не оптимизированный realtime-сервер.

Chatterbox Multilingual V3: 9/9 WAV, 24 kHz mono PCM16. После прогрева RTF примерно 2.6–3.2. Максимум torch allocated около 3.17 GiB. Первый тест существенно медленнее из-за прогрева. Отсутствует дополнительный русский модуль ударений. Скорость не является оценкой художественного качества.

В Chatterbox syllables исходный peak=1.00563, clipped_fraction≈0.0000200 (0.002%). При записи PCM16 есть небольшой клиппинг; файл намеренно не «улучшался», чтобы сохранить исходный тест. Остальные выводы о качестве нельзя получать из одной этой метрики.

У Qwen запрос четырёх протяжных гласных по две секунды дал файл всего 4.24 s: точное задание длительности в этом примере не выполнено. У Chatterbox аналогичный текст занял 4.16 s, но свободную инструкцию растягивания он вообще не принимает. Удлинение через повтор букв не равно управлению длительностями нот.

Для Qwen один и тот же текст с эмоциональной инструкцией дал 2.80 s, с нейтральной — 4.40 s. Это показывает изменение вывода при смене инструкции, но не доказывает, что слушатель распознает нужную эмоцию. Не выставляем модели баллы за эмоции без прослушивания.

## Музыка

ACE-Step 1.5 turbo: отдельный тест 30-секундной песни с оригинальными русскими строками. Используется CPU offload, 8 шагов, без дополнительной LM; фактические длительность, время и SHA находятся в results/ace-run2/manifest.json. Первая попытка остановлена при ненужной автоматической загрузке LM, причина и исправление сохранены.

Успешный результат: 30.00 s, 48 kHz stereo PCM16, генерация 39.75 s без времени загрузки модели. Все 19 WAV декодируются и содержат конечный ненулевой сигнал; суммарная длительность 106.48 s. Контрольные суммы сверены. Это проверка технической целостности, а не сертификат музыкального качества.

Проверять на слух: действительно ли слышны все заданные слова, насколько естественен русский, есть ли вокальные артефакты и подходят ли мелодия/тембр. Не объявляем точное следование 80 BPM, A minor или наличие качественного пения только по входным параметрам. Это генерация музыки с запрошенным вокалом, не точный MIDI/score-to-singing.

## Что выбирать дальше

Для актёрских реплик уровня стримерских голосов приоритет следующего сравнительного прослушивания — Fish S2 Pro / Drama 3 и Higgs TTS 3. Их локальные возможности на этом ПК ещё не измерены, поэтому объявлять их победителями по нашим WAV нельзя. Qwen и Chatterbox теперь дают воспроизводимую исходную точку.

Для музыкального вокалиста разделить выбор на: выразительность голоса; стабильный тембр; сохранение русских слов; мелодию и длительности; возможность получить сухую вокальную дорожку. ACE-Step проверяет генерацию музыкального фрагмента, а Seed-VC должен отдельно проверять перенос тембра уже спетой партии. Новая TTS-модель сама по себе не закрывает все эти задачи.
