# Локальные модели музыки — исследование 2026-11-04

Для этого ПК практически подтверждён ACE-Step 1.5 turbo: генерирует длинный
трек и бит с небольшим расходом памяти. MiniMax Music 3 выбран для независимого
сравнения через квантованный native runtime. Качество разных моделей нельзя
ранжировать по рекламным демо: ниже отделены возможности источников от наших запусков.

| Модель | Назначение | Пригодность для задачи / статус |
|---|---|---|
| ACE-Step 1.5 turbo | Песня по тексту, инструментал, редактирование музыки | Русский входит в заявленную многоязычность; реально выполнены два трека 250 с и бит 60 с |
| ACE-Step 1.5 XL turbo 4B | Более крупный вариант того же семейства | Заявлены 12 GB с offload+INT8, 16 GB с offload; на занятой другими программами карте меньше запаса, не запускался |
| MiniMax Music 3 | Полные песни по caption и lyrics | Для 16 GB выбран Q4/Q8/Q4 через audio.cpp; фактический результат в MUSIC_RESULTS.md |
| YuE2-3B | Песни, cover/edit, символическое планирование партитуры | Интересен для управления структурой; в карточке заявлены китайский/английский, русский здесь не проверен; не скачивался |
| Stable Audio 3 Small Music / Medium | Биты, инструментальная музыка, звуковые фактуры | Перспективен для инструментала; не выбран для точного исполнения русской лирики; gated-доступ, не запускался |

## Что говорят первичные источники

[ACE-Step 1.5](https://github.com/ace-step/ACE-Step-1.5) поддерживает caption,
lyrics и параметры музыки. В этой работе использован стандартный turbo с
8 шагами, без дополнительной LM. [XL model card](https://huggingface.co/ACE-Step/acestep-v15-xl-turbo)
описывает более крупный вариант и режимы экономии памяти. Свободные 16 GB на
пустой карте и карта 16 GB с запущенными пользовательскими приложениями — разные условия.
Лицензия ACE — MIT. Заявленная поддержка языка не гарантирует правильного
исполнения длинных редких слов вроде терминов в данном тексте.

[MiniMax Music 3](https://huggingface.co/MiniMaxAI/MiniMax-Music3) сочетает
авторегрессионный музыкальный LM и последующий синтез звука; поддерживает песни
до пяти минут, выход 32 kHz stereo. [GGUF package](https://huggingface.co/audio-cpp/MiniMax-Music3-GGUF)
предлагает баланс Q4/Q8/Q4. Его опубликованные измерения RTX 5090 не являются
измерениями нашего RTX 5080. [Native documentation](https://github.com/0xShug0/audio.cpp/blob/main/docs/models/minimax_music3.md)
предупреждает: duration_sec — бюджет AR, длинные запросы требуют больше памяти.
Зафиксированы model revisions и runtime, а не плавающая версия main.

[YuE2-3B](https://huggingface.co/m-a-p/YuE2-3B) интересен сочетанием текста и
символического музыкального планирования. Лицензия CC-BY-NC-4.0 ограничивает
коммерческое применение; это не MIT. Русский язык не следует считать
подтверждённым на основании англоязычного демо.

[Stable Audio 3](https://github.com/Stability-AI/stable-audio-3) предлагает
Small Music 433M (около 120 секунд) и Medium 1.4B (около 4,75 минуты, по
[model overview](https://github.com/Stability-AI/stable-audio-3/blob/main/docs/guides/model-overview.md)). Для битов
и атмосферных дорожек это отдельное полезное направление. Large API не отвечает
условию локального синтеза и исключён. [Small Music model card](https://huggingface.co/stabilityai/stable-audio-3-small-music)
требует доступа с принятием условий; gated-веса не скачивались. Условия
Stability Community License и Gemma надо учитывать отдельно от установки кода.

## Лицензия MiniMax и границы сравнения

Фактически скачанный `models/music/MiniMax-Music3-GGUF/LICENSE` —
**MiniMax-Music3 Community License**, не MIT. [Полный оригинал](https://huggingface.co/MiniMaxAI/MiniMax-Music3/blob/main/LICENSE).
Для коммерческого продукта предусмотрена атрибуция MiniMax-Music3; при совокупной
выручке соответствующих продуктов свыше $20 млн в год нужна отдельная авторизация.
Лицензия также содержит AUP и условия предоставления генеративного сервиса третьим
лицам. Локальный эксперимент не является запуском публичного сервиса.

Исследование не утверждает, что одна модель «лучшая на рынке». Реально проверенные
артефакты перечислены отдельно. Русская дикция, точное сохранение всех строк,
высокая носовая подача и сложная рэп-ритмика требуют прослушивания. Ни cloud APIs,
ни веб-демо не использовались для получения наших треков. Скачивание весов не
означает удалённый синтез. Pinokio и новые UI для этих запусков не понадобились.
