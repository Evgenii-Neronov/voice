# Rap4 hip-hop montage v3

Новая версия сохраняет исходную песню, исправленные субтитры и появление Ежи в конце. ADV удалено. Улица занимает 11,78%; остальное - новые нарисованные студия, метро, крыша, площадка, концертный зал и монтажные вставки с винилом, колонками и бумажным портретом. 31 монтажный план.

## Движения
Реально скачаны и использованы открытые аннотации AIST++: Middle/LA hip-hop. Лицензия CC BY 4.0, авторы и ссылки в CREDITS.md. Движения адаптированы под рисунок: замедлены, сглажены, разделены паузами и фразовыми жестами. У каждого из трёх героев отдельная последовательность; один исходный отрывок не повторяется в пределах его партии. Скорость рук ограничена. Это стилизованная адаптация танцевальных данных, а не профессиональный захват рэп-выступления.

## Локальные инструменты
- Python 3.12; точные версии пакетов в requirements.txt.
- Skia CPU: новые иллюстрированные сцены, 24 кадра/с, 2560 × 1440.
- Blender 4.5.9 Cycles OptiX: оставшиеся 32 секунды улицы, 12 рисунков/с, 12 samples, 4 bounces, GPU denoising.
- FFmpeg / NVIDIA NVENC: H.264, AAC 320 kbit/s, 24 кадра/с. Лицензии: https://ffmpeg.org/legal.html ; https://www.blender.org/about/license/ .
- Новые сцены используют рисованный свет; трассировка лучей применяется только к сохранённой улице.

## Сборка
В поставленном проекте есть рисунки улицы, готовая сцена Blender, фонемные данные, движение и исходный звук. Полный архив датасета не нужен для обычной пересборки.

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
$env:BLENDER_EXE = 'путь/к/blender.exe'
.venv/Scripts/python render_middle.py
.venv/Scripts/python run_street.py
.venv/Scripts/python assemble.py
```

Нужны FFmpeg и драйвер NVIDIA. Результат переносимого проекта записывается в `renders/`. Перед изменением движений сделайте копию проекта. `street_sprites.py` пересоздаёт три основных персонажа для уличных кадров. Ежи сохранён из предыдущего проекта. Для пересборки движения из исходного датасета укажите `$env:AIST_ARCHIVE`, затем запустите `build_motion.py`, `audit_motion.py` и пересоздайте рисунки/видео. Производственный архив датасета: `I:/VOICE/voice/models/motion/aistplusplus/keypoints3d.zip` (gitignored).

Для смены сцен и границ редактируйте `edit-plan.json`; для рисунка и камеры - `film_art.py`; для поз - `art.py` и `build_motion.py`; для титров - `subtitles.ass`. Движение рта и тайминг субтитров наследуются от исправленной v2. Текст и источник аудио не переписывались. Субтитры добавляются после эффектов: жёлтые, отступ снизу 144 px, только короткий `-`.

## Проверки и ограничения
`motion-validation.json`: 300 проверок соединения шеи, скорость рук, отсутствие повторного использования отрывка одним персонажем. `validation.json` в результатах: разрешение, длительность, полное декодирование, корреляция исходного звука, бюджет улицы и неизменность субтитров. Движущийся фрагмент проверяется по последовательным кадрам; это не заменяет полного просмотра со звуком. Виземы автоматические, сходство Ежи стилизованное, анимация остаётся ограниченной рисованной анимацией.

В Git сохраняются код, монтажный план, небольшие производные данные движения и отчёты. Большой датасет, видео, Blender-сцена и последовательности PNG не коммитятся. Локальная папка project содержит материалы для повторного рендера; предыдущие версии не заменены.

Для сборки уличной сцены с нуля: `python street_sprites.py`, `python ezhi_sprites.py`, затем `blender -b --python build_street_scene.py`. В поставленном проекте это уже сделано; сохранённые рисунки Ежи используются без регенерации.
