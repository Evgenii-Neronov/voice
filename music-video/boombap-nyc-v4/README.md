# NYC boombap v4 - 3D montage

Новая версия по `ADV-boombap-NYC-v3-1440p.mp4`. Исходная улица занимает **49,712%** кадров, новые объёмные сцены - 42,342%, рисованные граффити - 7,945%. Длительность 253,291667 секунды, 6079 кадров, 2560 × 1440, 24 fps. Предыдущие версии не заменены.

## Что изменено
- 14 длинных тире/аналогичных символов заменены на ASCII `-`. Остальные символы, тайминг и оформление субтитров сохранены: жёлтые, нижний отступ 144 px.
- 21 монтажный план: возвращения к принятой улице чередуются с виниловой студией, метро, крышей и индустриальной сценой со свистульками и вычислительными стойками.
- 3 короткие 2D-перебивки: цветные граффити растут из мазков в переплетённые круги и ветви. Это абстрактные авторские формы без букв.
- Новые 3D-вставки используют геометрию, перспективную камеру, текстуры, отражения и объём предметов. Камера проходит мимо колонн/предметов переднего плана. Люди остаются в сохранённых уличных сценах; новых персонажей или изменения внешности здесь нет.
- Исходный AAC-звук копируется из указанного пользователем MP4 без повторного кодирования.

## Локальные инструменты
Blender 4.5.9 LTS / EEVEE Vulkan, 16 samples, ray tracing; FFmpeg/NVIDIA NVENC для итогового H.264; Python 3.12, Skia CPU для 2D-графики. Зависимости в requirements.txt. 3D-сцены нарисованы геометрией локально; облачная генерация и новые нейросетевые веса не использовались.

## Пересборка переносимого проекта
Установите зависимости, добавьте FFmpeg в PATH, укажите путь к Blender:

```powershell
$env:BLENDER_EXE = 'путь/к/blender.exe'
python graffiti.py
python extract_street.py
python run_new_3d.py
python assemble.py
python verify.py
```

В проекте сохранены чистый уличный рендер `original-clean.mp4`, четыре Blender-сцены с упакованными текстурами, исходный звук `audio/original.m4a`, исходники и монтажный план. Результат пишется в `renders/`. Новые сцены можно редактировать в `sets/*.blend`; камеры и анимация вставок заданы в `render_shot.py`. Полная редактируемая сцена прежней улицы прилагается отдельно как `original-street-v3.blend`; её рендер не нужен, если улица не меняется.

Для создания новых наборов с нуля: `blender -b --python build_sets.py -- studio` (аналогично roof, metro, lab). Скрипт ищет текстуры по `ASSET_DIR` или в предыдущем локальном проекте; готовые .blend уже содержат текстуры. `plan.py` создаёт монтажный план и замену тире из предыдущей версии; при обычной сборке запускать его не требуется.

## Проверки и границы
`validation.json`: полное декодирование, размер/длительность/6079 кадров, идентичность звуковых AAC-пакетов, корреляция звука в начале/середине/конце, точная замена тире без иных правок, бюджет улицы. Проверены концепты каждой локации, рост граффити, движущийся переход по последовательным кадрам и выборочные кадры всего результата. Это не утверждение о полном просмотре со звуком.

Внешность и приближённая артикуляция прежних 3D-моделей сохранены. Новые планы - предметные перебивки; это не новые выступления людей в других локациях. В Git идут исходники, настройки, лицензии, небольшие превью и отчёты. Видео, .blend и исходные текстуры находятся только в локальном проекте и исключены из Git.
