# Seed-VC V2: реальный локальный A/B

comparison.mp3: 12 с прежнего V1 → 0.5 с пауза → 12 с V2 timbre → 0.5 с → 12 с V2 style.
Бит одинаковый, один общий gain без эха. V2 style преобразовал 12 с в 11.61 с;
для версии с битом применён atempo 0.9675 с сохранением высоты. Сырые сухие WAV
сохранены отдельно. Референс V2: первые 8 с русского ADV, одинаковый для обоих режимов.
V1 baseline использовал прежний 16.98 с референс, поэтому строгий A/B — V2 timbre vs V2 style.

Результаты: ADV timbre 14.87 с вычислений; ADV style 29.61 с; Ezhi style 14.13 с.
Пик torch allocated около 3.26 GiB. Все вычисления локальные. Веса не публикуются.
Это тест переноса стиля/акцента, не доказательство улучшения русского произношения.
Нужно сравнить на слух: возможны потеря флоу, изменение слов и сходства голоса.
