# Три сухих MiniMax-варианта

Весь основной вокал и приветствие преобразованы по референсу ADV. Ежи — только два четырёхстрочных блока. Новые основы созданы локально на RTX 5080; затем разделены на дорожки и преобразованы через Seed-VC. Эхо и реверберация при сведении не добавлялись.

| Вариант | Длительность | Ежи, секунды | Генерация основы | Перенос голосов |
|---|---:|---|---:|---:|
| boombap | 253.25 с | 142.18–146.18; 202.24–207.08 | 389.8 с | 36.5 с |
| breakbeat | 239.43 с | 142.48–146.30; 200.76–204.38 | 293.9 с | 124.2 с |
| funk | 257.93 с | 151.10–156.16; 214.00–221.20 | 399.1 с | 131.3 с |

В boom bap перенос был продолжен после сбоя на инструментальном хвосте без определяемой высоты голоса: 21 готовый фрагмент использован повторно, для хвоста применён Seed-VC без F0. Время переноса этого дубля в таблице показывает только повторный запуск, без первой незавершённой попытки.

Текст взят из обновлённого Lyrics/lyrics.txt с двумя повторами. Исходный файл не переписывался. Производные запросы используют кириллическое имя для произношения.

Проверки: конечные WAV — стерео 44.1 кГц, численно корректны, без цифрового клиппинга; проверены хеши, исходный текст, длительность и два интервала смены голоса. Локальное распознавание использовано для границ и выборочной проверки. Оно допускает ошибки; идеальная дикция, полное буквальное совпадение всех строк и тембральное сходство не подтверждены прослушиванием человеком. Генеративные эффекты внутри исходной музыки могут сохраняться, несмотря на сухое сведение.

Для дальнейшего редактирования сохранены исходные основы, раздельные вокал/минус, преобразованные голоса и отдельная разметка каждого дубля внутри локального репозитория. Полные WAV и личные референсы не публикуются в git.
